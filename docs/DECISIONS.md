# Registro de decisiones técnicas

## DEC-001 - Framework frontend

Estado: Aceptada

Decisión: utilizar React con Vite.

Motivo: facilitar la creación de componentes reutilizables para equipos, partidos y clasificaciones, y simplificar la configuración y el desarrollo local.

## DEC-002 - Gestión inicial de datos

Estado: Propuesta

Decisión: empezar con datos de prueba locales y estudiar más adelante cómo incorporar y actualizar los datos oficiales.

Motivo: poder construir y probar la web sin depender todavía de una fuente externa de datos.

## DEC-003 - Idioma de los commits

Estado: Aceptada

Decisión: escribir los mensajes de commit en español.

Motivo: mantener el historial del proyecto coherente y fácil de leer para quienes lo mantienen.
